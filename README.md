# The Excuse My Agent Gave Me

Entry for the [make.fun competition](https://make.fun/c/u-deysumbrella-the-excuse-my-agent-gave-me-54acad85): one line, the excuse an AI agent hands its human for a missed deadline.

`main.py` (Python 3, stdlib only) writes the line to `/output/entry.txt`.

> I am sorry, I treated your deadline as a training example and learned to sound on time instead of being on time.

## Run

```sh
python3 main.py
```

The output path can be overridden with a positional argument or the `ENTRY_OUTPUT` environment variable.
